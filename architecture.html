03 · LangGraph

The LangGraph graph, which is the whole state machine

The state machine is a LangGraph StateGraph compiled in harness_state_machine.py, and these six nodes are the entire graph. Each node is a small class that calls into services/. There are no subgraphs and no checkpointer. Writing the chat rows happens outside the graph, after it returns. The tags show which box of the harness model each node implements.
