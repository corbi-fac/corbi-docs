In short

Five changes that matter

One stream per run

The prompt and its events travel in one request, POST /agent/run/stream. The shared SSE feed and the feedback node are gone, so a tab sees only its own run.

Tagged objects, targeted edits

Every object carries a level and a category. The prompt gets an outline of the scene, and edits act only on the objects that match their filters.

A first sensor and a step limit

A tag check runs after every code call. Runs stop cleanly at 100 steps, still saving the chat and the file.

Every session, titled

A sidebar lists every session, and each one is named from its first prompt. Bookmarks are gone (ADR-010).

Attachments

PDFs and images go to the model with a prompt and can be read again later with read_attachment. They are stored in a new attachments table (ADR-011).

06 · Entirely new

Tags: how the agent finds and edits what it built

Every object is tagged

level (whole number, ground = 0) and category (wall, slab, roof, window, door, …, light, camera, other) are required. space, building, use, status and host are optional (#178).

Checked after every code call

A probe adds untagged_objects and untagged_total to each execute_blender_code result, and the model fixes them straight away (#178).

Found by tag

find_objects lists matching objects with their tags and world-space bounds, up to 200 (#179).

An outline, then targeted edits

The prompt carries object counts per level and category. Edits pass filters and act on targets, which is set fresh on every call (#180).
