# Corbi docs

Visual explainers for Corbi, published with GitHub Pages.

- `index.html`: home page linking the three pages
- `architecture.html`: how Corbi works today
- `saves-and-forks.html`: proposal for going back to earlier work without bookmarks
- `week-plan.html`: this week's work, as user stories

Static HTML with no build step. To publish: push to GitHub, then go to Settings → Pages and serve from the `main` branch, root folder.
